# Code of Conduct

## Our Standards

Participants are expected to:

- communicate respectfully;
- provide constructive technical feedback;
- avoid harassment and discriminatory behavior;
- respect privacy and security boundaries;
- focus discussions on the project and its users;
- report security concerns privately;
- avoid publishing credentials or private logs.

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment;
- threats;
- personal attacks;
- discriminatory conduct;
- publication of private information;
- deliberate disruption;
- knowingly unsafe contributions;
- intentional bypass of security controls;
- disclosure of vulnerabilities before coordinated review.

## Technical Collaboration

When reviewing code:

- discuss the implementation, not the person;
- explain security or design concerns clearly;
- suggest testable improvements;
- respect maintainers' responsibility for project safety;
- disclose uncertainty when a claim is not verified.
