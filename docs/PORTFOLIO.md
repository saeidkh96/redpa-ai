# Portfolio Description

## RedPA AI

RedPA AI is a production-oriented Agentic AI platform designed and developed
with FastAPI, PostgreSQL, Qdrant, Redis, Docker, MCP, A2A, OpenTelemetry,
Prometheus, Grafana, and Tempo.

The platform supports multi-agent orchestration, Retrieval-Augmented
Generation, remote specialist agents, human approval, durable workflow
resumption, semantic Agent Memory, background jobs, rate limiting,
idempotency, distributed tracing, structured logging, and Kubernetes-ready
deployment.
