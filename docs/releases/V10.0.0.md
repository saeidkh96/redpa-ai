# RedPA AI v10.0.0

## Governed Agent Runtime

RedPA AI v10.0.0 introduces persistent governance as a first-class part of agent execution.

The release connects policy decisions, Human-in-the-Loop approval, lifecycle state, operations recovery, trace events, and evaluation into one governed execution path.

### Highlights

- Persisted V10 governance runs and execution events.
- Explicit lifecycle management including `BLOCKED -> RUNNING` resume after approval.
- Governance integration across agent runtime and autonomous operations.
- Policy decisions persisted with risk, decision, executability, matched rules, and policy version.
- Dedicated Spring Boot Policy Service included in the primary Docker Compose stack.
- Verified approval-gated Docker recovery through the RedPA Ops Agent.
- Evaluation linkage for completed governed runs.
- OpenTelemetry/Tempo release hardening.
- Version alignment across backend, frontend, Python SDK, Helm, Docker Compose, and CI.
- Expanded V10 GitHub Actions governance gate.

### Verified E2E path

```text
RUNNING
 -> REVIEW / executable=false
 -> BLOCKED
 -> human approval
 -> REVIEW / executable=true
 -> RUNNING
 -> remediation
 -> recovery verified
 -> COMPLETED
 -> evaluation
```

The release-candidate E2E run recovered a deliberately stopped Research Agent, restored it to `running`, completed the governance lifecycle, and recorded an evaluation score of `1.0`.
