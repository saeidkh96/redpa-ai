# RedPA AI v19.1.0

Release date: 2026-08-20

## Overview

V19.1 advances the V19 enterprise cloud foundation from infrastructure
preview into a validated AWS development deployment while extending the
platform's governed enterprise integration capabilities.

## AWS Foundation

The Pulumi-managed development foundation was deployed and validated in
AWS eu-central-1.

Validated foundation resources:

- RedPA VPC
- ECS cluster with Container Insights
- Immutable ECR backend repository
- CloudWatch log group with 30-day retention

A post-deployment Pulumi preview reports the infrastructure as unchanged.

This release does not claim that the complete RedPA application workload
is publicly deployed or serving production traffic from ECS.

## Microsoft Governed Approval

V19.1 introduces a Microsoft/Power-Automate-compatible governed approval
boundary.

Validated behavior includes:

- authenticated approval request API
- persistent HumanReview creation
- pending approval state
- authenticated approval decision callback
- pending -> approved lifecycle
- reviewer evidence persistence
- PostgreSQL persistence
- backend restart persistence

No live Microsoft tenant connection or embedded Microsoft credentials are
claimed by this release.

## Governance Analytics

V19.1 adds an enterprise governance analytics service and API boundary for
aggregating governance/runtime evidence.
