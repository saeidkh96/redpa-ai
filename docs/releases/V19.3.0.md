# RedPA AI V19.3.0

## AWS Managed Data Layer

V19.3 extends the V19.2 AWS ECS/Fargate runtime with a real managed PostgreSQL data layer on Amazon RDS.

### Added

- Private Amazon RDS PostgreSQL instance in `eu-central-1`.
- Dedicated database subnets across two availability zones.
- Database security group allowing PostgreSQL access only from the ECS backend security group.
- Encrypted RDS storage.
- AWS Secrets Manager database connection metadata.
- ECS backend wiring to the managed RDS endpoint.
- One-off Fargate validation workflow for real database connectivity.
- Real Alembic migration execution against the managed RDS instance.
