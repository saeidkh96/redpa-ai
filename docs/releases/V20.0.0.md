# RedPA AI V20.0.0

## Enterprise Production Deployment

RedPA AI V20.0.0 promotes the AWS deployment line from production-readiness validation to a dedicated, validated production stack while preserving the existing development environment.

### Added

- Dedicated Pulumi `prod` stack in `eu-central-1`.
- Production-specific AWS physical resource identities.
- Two-task ECS/Fargate production floor.
- Application Auto Scaling registration for the ECS service.
- CPU target-tracking policy at 60%.
- Memory target-tracking policy at 70%.
- Production scaling range from 2 to 4 tasks.
- Production SNS alert topic with CloudWatch alarm actions.
- Optional configuration-driven email subscription boundary.
- Production-specific runtime version/environment contract (`20.0.0`, `production`).
- Production startup hardening for secrets, database URL encoding, and allowed hosts.
- Liveness path independence from Redis-backed rate limiting.

### Release artifact validation

The V20 container was built, validated locally under production settings, published to ECR, and promoted from the validated RC artifact to the final `v20.0.0` tag. The final and RC tags were verified to reference the same validated image digest.

### Development-stack compatibility

The AWS source was parameterized so production resources receive V20 production identities while existing development resource identities remain unchanged. Development previews were repeatedly validated as zero-drift during the migration.

### Current boundaries

- ALB ingress is HTTP; HTTPS/custom-domain/ACM integration is not claimed.
- WAF is not claimed.
- RDS remains single-AZ.
- RDS automated backup retention remains one day.
- Regional and multi-region failover are not claimed.
- SNS alarm routing is active, but an email subscriber is not claimed unless `alert_email` is explicitly configured.
- V20 is the enterprise production deployment release; repository-wide package/version metadata that remains on the 19.7 application baseline is not silently represented as globally synchronized to 20.0.0.
