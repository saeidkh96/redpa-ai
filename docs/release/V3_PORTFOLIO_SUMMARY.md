# RedPA AI v3 — Portfolio Summary

## Project

RedPA AI is a production-oriented agentic AI platform demonstrating the design
of reliable, observable, governable AI systems.

## Engineering story

The project evolved from a FastAPI agent runtime into a multi-service platform
with:

- agent orchestration;
- RAG;
- MCP and A2A;
- durable workflows;
- Human-in-the-Loop;
- semantic memory;
- multi-LLM routing;
- evaluation;
- Java/Spring Boot governance;
- event-driven messaging;
- RBAC and multi-tenancy;
- Azure/Pulumi infrastructure;
- observability and production hardening.

## Honest scope

RedPA demonstrates engineering capability; it does not claim production
certification, live Azure deployment, or fully configured third-party OAuth
without the corresponding real infrastructure and credentials.
