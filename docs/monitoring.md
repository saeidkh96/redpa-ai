# Monitoring

## Prometheus

RedPA exports application metrics for:

- HTTP requests;
- response status;
- latency;
- tool execution;
- MCP execution;
- workflow behavior.

## Grafana

Grafana dashboards visualize operational metrics.

## Recommended Production Metrics

- planner route distribution;
- tool error rate;
- MCP server availability;
- MCP latency;
- research duration;
- LLM duration;
- human-review queue size;
- approval latency;
- RAG retrieval latency;
- database latency;
- background workflow retries.
