# RedPA AI — Architecture Documentation

Phase 14 establishes a durable architecture baseline for RedPA AI.

This documentation set contains:

- Domain-Driven Design bounded contexts;
- Clean Architecture dependency rules;
- C4 architecture views;
- arc42 architecture documentation;
- Architecture Decision Records (ADRs);
- architecture verification tests.

The goal is to make the architecture explicit and reviewable without rewriting
working runtime code unnecessarily.
