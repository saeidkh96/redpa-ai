# Contributing

Thank you for contributing to RedPA AI.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Add or update tests.
4. Run formatting, linting, and tests.
5. Update documentation when behavior changes.
6. Open a pull request with a clear explanation.

## Branch Names

```text
feature/short-description
fix/short-description
docs/short-description
refactor/short-description
```

## Commit Style

Prefer clear imperative commits:

```text
Add workflow resume validation
Fix planner route normalization
Document Prometheus setup
```

## Pull Requests

A pull request should explain:

- the problem;
- the implementation;
- tests performed;
- API or migration impact;
- screenshots for UI or dashboard changes;
- follow-up work.

Never include secrets, real access tokens, private documents, or production data.
